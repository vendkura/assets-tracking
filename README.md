# Industrial 3D Asset Detection Pipeline
### LiDAR Point Cloud Processing Demo

A Python pipeline demonstrating the core steps of automated industrial asset detection from 3D point cloud data.

---

## Context

This pipeline simulates what a real system would do with LiDAR scans of an industrial facility (petrochemical plant, food processing, automotive):

1. **Capture** — LiDAR scanner generates millions of (x,y,z) points
2. **Preprocess** — clean noisy, cluttered scan data
3. **Segment** — separate individual components (pipes, valves, elbows)
4. **Extract** — output structured asset data (dimensions, positions, type)

This structured output feeds directly into asset management platforms like **Antea** to build a **digital twin**.

## Project Structure

```
industrial_pipeline/
├── scripts/
│   ├── 01_generate_scene.py       ← Synthetic LiDAR scan generator
│   ├── 02_preprocessing.py        ← Downsample + denoise + normals
│   ├── 03_segmentation.py         ← RANSAC planes + DBSCAN clusters + classify
│   └── 04_feature_extraction.py   ← Dimensions, endpoints, asset register
├── data/
│   ├── raw_scene.ply              ← Generated by script 01
│   ├── preprocessed.ply           ← Generated by script 02
│   ├── segmented.ply              ← Generated by script 03
│   ├── segments/                  ← Individual component .ply files
│   └── asset_register.json        ← Final structured output
└── outputs/
    └── feature_extraction_report.txt
```

## What the Scene Contains

The synthetic scene simulates a section of an industrial plant with:

| Component | Description |
|-----------|-------------|
| Pipe A | Horizontal pipe (X direction) |
| Pipe B | Horizontal pipe (Y direction) |
| Pipe C | Vertical riser (Z direction) |
| Pipe D | Wider pipe at different height |
| Pipe E | **Partially occluded** pipe (key challenge) |
| Elbow A | 90° bend connecting Pipe A → B |
| Elbow B | 90° bend connecting Pipe B → C |
| Valve A | Gate valve on Pipe A |
| Valve B | Larger valve on Pipe D |
| Background | Clutter/noise simulating wall/floor LiDAR returns |

## Key Concepts Demonstrated

- **Voxel downsampling** — efficient density reduction
- **Statistical outlier removal** — noise cleaning
- **Normal estimation** — surface orientation for shape detection
- **RANSAC plane detection** — floor/wall removal
- **DBSCAN clustering** — grouping points into components
- **PCA-based axis fitting** — finding pipe directions and endpoints
- **Occlusion handling** — flagging partially hidden components
- **Asset register generation** — structured output for digital twin
